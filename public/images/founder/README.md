# Dropping In Your Real Stilt-Walking Photos

Drop 1 to 3 photos of yourself walking on stilts (`.jpg`, `.jpeg`, `.png`, or `.webp`) into this folder:
`/Users/beaucarnes/Documents/beauvideo/stiltwalker/public/images/founder/`

Recommended filenames (any `.jpg`/`.png`/`.webp` works automatically!):
- `beau-stilts-1.jpg` (main featured portrait in the "Meet the Creator" section)
- `beau-stilts-2.jpg` (optional action/crowd shot)

Then run:
```bash
npm run build
```

The build script automatically detects images in `public/images/founder/` and upgrades the Founder card on the homepage and `/join/` page into a multi-photo real stilt-walker showcase with Schema.org `Person` E-E-A-T markup!
